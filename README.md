# ze-ai-chat-acceptance-fixture

Small public fixture used to verify ZeAiChat scaffold acceptance criterion 5: GitHub source
mirroring into the wiki and issue mirrors, then offline retrieval over the indexed chunks.

## Observatory telescope calibration

The observatory telescope calibration procedure rotates the equatorial mount by a
quarter turn, then records the quasar drift against the sidereal clock. Calibration is
complete when the quasar drift stays below one arcsecond for a full minute.

## Widget assembly

The widget assembly step fastens the brass gimbal to the mounting plate with four
countersunk screws. Over-tightening the gimbal warps the plate, so torque each screw
to the marked value and stop.
